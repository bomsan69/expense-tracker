# Expense Tracker UI Design Handoff

This package was generated from the provided 16-slide `expense_tracker_uiux_spec_v1(1).pptx`, using the attached design brief. It contains:

- `ui-mockups.pdf`: 12 visual plates (all nine required screens + three state studies), 390×844 mockup shown beside rationale.
- `mockups/*.png`: individual 390×844 source image previews at 2× resolution.
- `design-system.md`: palette, type, rhythm, accessibility, navigation.
- `design-tokens.json`: machine-readable design values.
- `globals.css`: Tailwind CSS v4 token proposal with shadcn-compatible names.
- `component-specs.md`: reusable component/variant and icon mapping.
- `screen-design-map.md`: Screen ID-to-component and interaction mapping.
- `implementation-guide.md`: Next.js App Router + Tailwind handoff.
- `open-decisions.md`: proposed assumptions vs unapproved behaviors.

This is a **static visual handoff**, not a coded or approved UI. Mockups use illustrative content; check original PPTX for authoritative product behavior and unresolved decisions. The live product must implement keyboard access, real validation, and chart data. This package makes no claim of having validated interaction in a running app.
